# Independent conditional rooted8 catalogue coverage v1

Use the independently covered2,750 prism-free rooted7 classes as a pinned finite
universe. Enumerate every128 new-vertex neighborhoods for each parent, exactly
352,000 labelled attempts. Test local edge/nonedge common-neighbor caps1/2 and
every six-subset for a triangular prism by independent bit-neighbor tests.
Every qualifying extension must belong to the claimed rooted8 catalogue, and
every claimed class must be generated. Induction then gives complete coverage
of every prism-free rooted8 flag applicable to the conditional target.

Independently enumerate all720 free-label permutations of each claimed class.
Require its raw representative be the minimum image and require distinct classes
have disjoint labelled orbits. A uint32 array indexed by the27 unconstrained edge
bits stores each exact canonical orbit identity, so all subsequent coverage tests
avoid the producer's canonicalizer. This costs512MiB for the array and under1GiB
estimated total, versus an unbounded dictionary of labelled images. No discovery
module or archived catalogue is imported.

Declare1800seconds outer/1740seconds worker including source/input hashing and
the full orbit/augmentation loops,60seconds reserve; six hours is a ceiling.
Earlier root7 coverage took3seconds, but the new finite class/orbit population is
about20,253*720 images and augmentation352,000. Save immutable progress records
every1000 catalogue members and every250 parents; on stop state the exact
completed prefix and unmet final coverage requirements. Known prism/missing-edge,
cap violation and empty-graph controls precede substantial loops; missing orbit
and missing generated-class controls veto coverage.

Success requires exact equality of all saved retained classes, counters and first
generating witnesses. Claim scope is a complete finite conditional catalogue only,
no target automorphism, ordinary marked/product row approval, construction,
exclusion, new prism-absence theorem, numerical solver or target resolution.
