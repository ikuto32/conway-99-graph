# One native oriented-triple pilot

Frozen before any preflight or research invocation. Question: does the exact
800-variable, 109340-clause oriented-triple projection have a cover?
The population is all mixed balanced local/even-phase assignments on the one
saved six-prism support. No odd offsets, column caps, residual D, or unrestricted
target coverage are asserted. SAT is only a candidate cover. UNSAT requires
complete independent proof replay and independently checked scope equivalence.

Selection: first native result for the unmodified instance; default seed.
One attempt, 60 seconds GNU wall timeout, 1000000 conflict setting, 4 GiB address
space, 10 GiB trace limit, 5-second kill grace, 70-second Windows outer guard.
No separate CPU limit. The observed conflict count may exceed the setting and
must be retained. No retry. UNKNOWN stops this pilot but not the research program.
Before launch reserve 21 GiB host and 11 GiB ext4. No files are deleted.

Require exact independent encoding and calibrated object reports, binding the
same raw support, model, scope, CNF and producer sources. Object calibration
also binds this driver/spec and encoding report. Rehash all audit-bound inputs.
The native/parser/ext4 helpers and native CLI/trace-location calibrations are
shared engineering components; they are not independent mathematical verification.

Preserve command, versions, hashes, output and native receipt. Immediately
after a returned native process copy the raw trace from ext4, with exact hashes
on both sides, before later analysis. The earlier batch's deferred trace copy
found its temporary directory unavailable; this new protocol changes archival
timing without altering that historical record. A copy failure is recorded and
does not establish proof replay. No complete-copy assertion after an outer-guard
expiry. Copy/hash time is outside the solver allocation and recorded separately;
no hard end-to-end duration promise is made.

All checks use integers. SAT assignment must contain all 800 IDs, satisfy every
actual clause, and decode a complete directed cover. Producer checks leave it
CANDIDATE; the independent checker must reconstruct all raw arcs and conditions.
No acceptance tolerance is used. A full graph would need a separate SRG validator.
