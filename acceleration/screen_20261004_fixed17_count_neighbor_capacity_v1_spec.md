## Necessary mathematics

For any actual target split as `[H C; C^T X]`, the target identity gives
`HC+CX+C=2J`. A focal outside vertex of type `T_i` therefore needs

* `D_i=14-|T_i|` distinct outside neighbors;
* `b_i(u)=2-1_{T_i}(u)-sum_v H[u,v] 1_{T_i}(v)` incidences at support point u.

Expand all copies as exact labels `[type_index, copy_index]`, in increasing type
and then copy order. For each positive type choose the focal label `[i,0]` and
exclude exactly that label. All copies of type i have identical screen inputs;
the same bound applies to each. This is relabeling of distinct slots, with no
assertion that actual same-type vertices have equal or equitable neighbor
profiles. Zero-count types are retained in the type universe but have no focal
row. No positive-weight filter from a previous LP is used.

For every other copy, use the independently qualified raw pair `combined_bits`.
Allowed bit 1 is necessary for eligibility. A singleton set `[1]` makes that
copy mandatory. `[0]` excludes adjacency; `[]` forbids coexistence off diagonal,
or multiple distinct copies on the diagonal. `[0,1]` gives a free eligible slot.
The code repeats the empty-bit population checks before screening. Equal types
refer to distinct vertices; the own copy is never a neighbor. The code does not
assume that the actual pair packet has zero forced-adjacent pairs.

Let f be mandatory count and d=D-f. Degree capacity requires
`0<=d<=number_of_free_slots`. For each support subset Q let `R=sum_{u in Q} b(u)`
and g be the total `|T_j intersect Q|` of all mandatory copies. Sort the free
copy scores, each copy appearing once even when its type is repeated. The exact
minimum is g plus the d smallest scores, and the exact maximum is g plus the d
largest scores. The closed necessary interval is `minimum<=R<=maximum`.
For d=0 both free sums are zero. Lower/upper achieving free-copy labels are
saved, with deterministic integer-score and label tie ordering.

For support size17, Q order is every lexicographic singleton, then pair, then
triple, followed by the full ordered support. This is exactly
`17+136+680+1=834` distinct subsets. It does not test all `2^17` subsets.
Singleton scores are zero/one, so the same sorted-slot rule includes the exact
point-incidence and total-capacity bounds. Different Q passes need not share a
neighbor selection.

If d is negative or exceeds free capacity, every Q demand is still retained,
but min/max and their achieving labels are null: there is no feasible
D-neighbor subset over which such extrema could be defined. The type record
and first violation record state `MANDATORY_CAPACITY` or `NEIGHBOR_CAPACITY`.
Otherwise every one of the 834 rows contains exact integer extrema, including
failed rows. No first-failure short circuit skips later types or Q rows.
