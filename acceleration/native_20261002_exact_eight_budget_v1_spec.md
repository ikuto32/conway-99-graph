# Policy-aware exact-eight native producer v1

This new Linux-only producer preserves the historical driver and all historical
receipts. Imports do not start research. Modes are `controls`, `preflight`, and
`research`. New research requires `INDEPENDENT_EXACT_EIGHT_POLICY_NATIVE_DRIVER_PASS`
binding this source, this specification, `command_deadline.py`,
`run_compute_command.py`, the new environment's pyproject/lock and exact native
CaDiCaL binary. Old object calibration is mathematical evidence for the unchanged
formula bytes, not approval of changed execution.

Run the **outer supervisor inside Linux**. Its complete command allocation starts
before uv setup and all hashing, evaluation and transfer. The worker's explicitly
shorter immutable deadline is a contained sub-allocation. No child resets either
deadline. Normal native children remain in the outer timeout process group;
their GNU timeout uses `--foreground`. No `wsl.exe` timeout provides containment.

Suggested batch05 first allocation: outer900 seconds, producer870 seconds,
per-case requested120 seconds, producer shutdown/transfer reserve35 seconds.
These are explicit invocation parameters, not new research defaults. The basis
is 64 batch03 native evaluations taking56.59 seconds wrapped/163.33 seconds
end-to-end, and batch04 taking51.68/183.66 seconds. Both batches produced about
155 MB of proofs. Changed environment, file-system latency and unknown difficult
cases make those estimates uncertain. There is no calibrated success probability.
An early SAT/UNKNOWN/resource stop preserves the prefix, defers the remaining
cases for reassessment and proves no exclusion. A subsequent allocation may use
a separately authenticated continuation; there is no automatic resume/retry.

Retain exact seed0, one-million conflict limit,4 GiB address space,256 MiB proof
limit,64 GiB retained-artifact ceiling,32 GiB host free and2 GiB ext4 free reserves.
These restrictions are appropriate to this cheap literal-profile wave, not a
general nonexistence or impracticality claim. Literal formulas encode fixed six
prisms Hadamard support, exact Gram and within-triplicate caps; cross-triplicate
caps and residualD are omitted. No target automorphism is assumed.

The worker authenticates selected formula files, the frozen selection,
consolidation,792-case universe, exact encoding/object gate bytes, and each
selected CNF/model/scope/profile against those gates. It does not rehash the
approximately20,040 transitive historical inputs of each old report. That reuse
is disclosed. Fresh independent verification must bind exact raw outputs and
their declared scope. An UNSAT exit20 alone is pending complete DRAT replay.
SAT output is a raw assignment pending independent decoding/factor checking;
it cannot resolve Conway-99 without a complete independently checked99 graph.

Receipt interface:

* `manifest.json`: schema `EXACT_EIGHT_POLICY_NATIVE_BATCH_V1`, mode, exact actual
  command/cwd, caller source commit, Python/platform/tqdm version, input hashes,
  exact limits and requested allocations, outer supervisor invocation/manifest
  hash, selected IDs, criteria and limitations.
* `case_NNNN/launch.json`: schema `EXACT_EIGHT_POLICY_NATIVE_LAUNCH_V1`, literal
  case/attempt, exact native Linux argv, CNF descriptor, ext4 proof path, actual
  dynamically bounded seconds, unchanged limits and prelaunch deadline snapshot.
* `case_NNNN/solver.receipt.json`: schema `EXACT_EIGHT_POLICY_NATIVE_RECEIPT_V1`,
  exact argv/cwd, observed exit/time, guardPID/group, producer stop reason,
  reaping observation, current Linux solver/checker process snapshot, limit
  dictionary, log paths/hashes. This is raw evidence, not mathematical approval.
* `case_NNNN/summary.json`: schema `EXACT_EIGHT_POLICY_NATIVE_CASE_V1`, raw formula
  record, authenticated launch/receipt, raw proof path/hash/bytes and full copy
  equality, raw classification, no independent approval or target resolution.
* `checkpoint_NN.json`: completed ordered prefix and explicit pending suffix.
* `summary.json`: schema `EXACT_EIGHT_POLICY_NATIVE_BATCH_RESULT_V1`, raw case
  references/hashes, attempted/completed evaluations, native call count, explicit
  pending IDs, stop reason, unmet verification requirements. Counts exclude
  automatic retries (there are none). There is no target-wide coverage measure.
* `failure.json`: saved on a caught interruption/error with known completed
  prefix and pending IDs. ext4 workspace descriptors precede each launch, so
  raw outputs can be recovered even if proof transfer is interrupted. Hard-kill
  failure may leave only the latest checkpoint and raw Linux workspace; obtain
  actual supervisor cleanup observation before launching further work.

`controls` produces the exact tiny SAT formula with3 clauses and the matching
UNSAT formula with4 clauses, through the same native worker and copying path.
It also invokes a foreground timeout on a30-second sleeper with0.2-second guard.
An independent verifier checks complete SAT assignment/CNF, complete tiny DRAT
proof, corrupt/wrong-input proofs, receipt corruptions, group identity and outer
supervisor cleanup. A separate outer-supervisor deadline test with a spawned
sleeping descendant establishes observed group cleanup, including descendants;
the ordinary foreground timeout alone does not claim to kill all descendants.

Locked setup/execution uses
`/root/.local/bin/uv run --locked --project acceleration/native_budget_env_v1`.
The new environment pins `tqdm==4.67.1`, Python>=3.12,<3.13; all other worker
imports are standard library plus the existing policy helper. Prefer an ext4
`UV_PROJECT_ENVIRONMENT` for this Linux environment. The outer supervisor can
use the observed Linux stdlib Python3.12.3 without installing packages, then
wrap the locked uv command so environment/setup overhead remains within the
one invocation. Actual interpreters and lock hashes are saved.

No claim is promoted by this producer; external review and ledger registration
are separate. Positive/corrupted engineering controls test their specific
behavior and do not establish unrestricted coverage or mathematical resolution.
