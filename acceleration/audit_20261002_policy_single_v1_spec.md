# Independent generic native v2 review, checker version 1

This checker authenticates `native_20261002_budget_single_v2.py` and its explicitly
shared frozen v1 helpers from raw manifests, without importing either producer.
It imports only independently authored JSON/path/assignment readers and the
calibrated exact DRAT checking core v2. Every producer/shared source, specification,
deadline helper, Linux supervisor, locked native environment and native binary
must match the current manifest and gate hashes. Actual raw command vectors are
reconstructed independently, including all planned memory/file limits, seed,
conflict cutoff or explicit null reason, paths and dynamic timeout.

Calibration uses the exact two-variable three-clause SAT and four-clause UNSAT
fixtures. Exhaustive truth checks and complete raw assignment checking are
separate from the native producer; every complete tiny UNSAT trace is replayed
by the source-authenticated independent DRAT-trim binary. Wrong-CNF, fresh-unit
and empty-only invalid proofs and malformed receipt controls must fail. The
additional sound short DRAT trace is expected-valid for the independently
documented reason preserved in `audit_20261002_exact_eight_policy_v2_spec.md`.

The containing Linux supervisor must have exited zero with a reaped live-empty
process group, and the independent descendant control report must bind the same
current supervisor/deadline source hashes. These are calibrated small engineering
controls, not a hard-real-time or cross-host containment theorem. Current process
observations are required before every future scientific launch.

The first calibrated configuration is 8 GiB address space, 4 GiB proof cap, seed 0,
no conflict cutoff with an explicit reason, 32 GiB host-free reserve, 8 GiB ext4
free reserve and 12 GiB aggregate artifact ceiling. The gate's
`tested_configuration` excludes only native/producer/shutdown timer values; the
shorter control timers are recorded explicitly. Any source/options/resource
configuration change needs new applicable controls or a separate impact review.
The driver must not substitute the previous v1 gate for this new approval.

`outcomes` authenticates each frozen plan input and historical mathematical gate
binding. UNKNOWN authenticates preserved partial artifacts but adds no exclusion.
Research SAT stays pending a separate complete exact graph/object validator.
Conclusive UNSAT receives exact-instance approval only after complete independent
DRAT replay; encoding equivalence and unrestricted coverage are separate proof
obligations. A derivative learned-clause CNF is never automatically identified
with its original input. Proof-preserving continuation needs independently checked
prefix/state semantics and eventual combined proof replay against the original.

Reports bind exact commands, timezone-bearing timestamps, source commit, source
and artifact hashes, observed native tool versions, raw control/receipt results,
and explicit limitations. SHA-256 identity is not artifact availability. Evidence
is LOCAL_ONLY until separately transported/published and replayed. All outputs are
created exclusively at fresh paths. This checker runs through the current
supported Windows Job supervisor with an explicit per-invocation allowance.
Checker children use the same remaining deadline; no historical 60-second solver
or 180-second checker cutoff is imposed.

The independent verifier is `/root/checkpoint_audit`; the new producer's author
is `/root/native_driver`, and native execution is performed by `/root`. Shared
trusted components include Python, OS/SHA-256, the frozen independent source
authenticator, the preserved DRAT-trim implementation, reviewed portability shim,
compiler and runtime. No formal, diverse-checker or external review is asserted.
