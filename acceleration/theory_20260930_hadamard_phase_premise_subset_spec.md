# Candidate reduction of the second branch's phase premises

Question: can the existing GF(3) contradiction be certified after leaving
some of the twenty group parity patterns unspecified? This is a cheap exact
screen on one fixed support, not enumeration or target-level coverage.

Freeze the original 120-variable phase system and its independent complete
branch audit. Select the first required local same-sign phase difference,
whose group is zero. All column-gauge equations remain unconditional.
A local mixed-group equation may be retained only when that group's parity
pattern remains fixed. A coordinate-pair equation may be retained only when
all five containing groups remain fixed, including groups absent from its
visible coefficient support. Every retained pattern is the original saved
pattern. The target functional's group must remain fixed.

Start with all twenty groups. In descending order 19 through 1, try removing
one group. Accept a removal exactly when incremental elimination over GF(3)
expresses the target functional in the span of the retained equations. Save
all attempts, including failures, and the final literal row-combination
certificate against the original matrix. No random seed or floating point.
This deterministic greedy result is not a minimum-cardinality claim.

Run tiny positive and deliberately corrupted certificate controls before the
screen. At most twenty span calculations including the initial calculation;
one 60-second cooperative total allocation, no SAT/LP/native calls. No retry.
The only success criterion is a literal row-combination identity with fewer
fixed group patterns than the original twenty. Failure to shorten is not a
new mathematical exclusion. Any shortened conditional exclusion needs
independent review of the row dependencies and certificate before use as a
SAT clause. Preserve every source, attempt and artifact.
