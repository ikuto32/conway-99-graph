# Scientific hypergraph saved-object auditor v1

The adapter author also authored the annealer producer. Its own execution is
preliminary, not independent approval. Another agent must independently execute
and review this path and own any scientific verification claim. The adapter
imports only the independently authored audit_20261002_hypergraph_controls_v2
helpers (graph, state parser, RNG/replay) by /root/checkpoint_audit, standard
Python/tqdm and shared policy helpers. No producer module is imported. All helper,
gate, source/spec/environment, raw run and artifact hashes are pinned/disclosed.

Full saved-object checks cover initial/current/best and every immutable scientific
checkpoint: exact231 linear triples on99points, degree7 occurrences, degree14
point adjacency, binary symmetric zero-diagonal graph, every unordered common-
neighbor count, complete CN cache, integer energy and best order, wellformed RNG
and counter order. Compare saved counter monotonicity and fixed configurations;
do not infer exact whole-trajectory counts from these consistency checks. Each
current/best object additionally gets a separate scalar99x99 integer matrix
product with all9801 ordered entries and exact pair-residual score. No floating
score or matrix certificate is used.

Check any raw current/best matrix file against the corresponding final labelled
triples. Frozen producer v1 exports best.adj only: report missing raw current.adj
explicitly and export a separately reconstructed current matrix, preserving all
original bytes. Every zero target score feeds the complete99/14/1/2 validator;
all9801 entries must satisfy A^2=12I-A+2J, and all size/binary/diagonal/symmetry/
degree checks pass. Rook9E0 is a different-parameter control, never a99certificate.
A successful internal matrix check still needs the user's independent discovery
rule, an additional checking path if meaningful, and external review.

Sparse trace verification checks the exact predeclared selected step population.
Each record receives syntax/local RNG/configuration checks, conditional on its
recorded starting RNG/admissibility when unanchored. Full graph/delta/decision
replay is performed only from an exact complete saved state or a contiguous
already-replayed frontier. Unanchored gaps remain explicitly unchecked. Never
describe sparse record checking as a complete trajectory or exhaustive search.

Calibration uses known rook9 SRG identity (all81 integer entries) and valid99
hypergraph domain with positive energy, then deliberately corrupted matrix edges,
loops, symmetry, binary data/shape; triple/score/cache/counter/RNG states; and
rook9/n99 scope gating. There is no known-valid target99 positive fixture; record
that limitation. Calibration also binds the independent helper finite-control
gate; no new scientific native invocation occurs.

Suggested calibration allowance160s outer130s worker (small fixtures; matrix
product plus controls), with20s worker reserve under the current local supported
supervisor and root locked uv environment. Scientific saved-state auditing is a
separate command with allowance chosen from actual saved-file/trace population;
it includes hashing, complete object checks, anchored replays and output hashes.
The auditor uses CommandDeadline and preserves failure outputs. No native search,
ledger edit, git index modification or automatic claim promotion.
