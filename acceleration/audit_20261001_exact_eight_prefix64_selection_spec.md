# Reusable independent prefix64 prebuild identity review

Freeze this source and spec before execution. No request, selected IDs, output
directory, number of prior proofs, or batch number has a source default. Require
explicit --request/--request-sha256, --selection/--selection-sha256,
--launch-plan/--launch-plan-sha256, and --out NEW. Await actual producer output
pins from root before any invocation. This checker never imports the producer.

Authenticate the complete existing792 manifest using the frozen independent
campaign path. Reuse only frozen independent v3 proof-identity helpers: every
supplied complete proof gate, claim binding, literal count, exact CNF/scope,
complete trace, and accepted replay receipt is bound. Respect first12
SAT_pending versus next32/generic SAT_verified schema differences. Reject
duplicate gate paths or case IDs. Derive counts from reports, normalize optional
completed_cases fields, and require enough members for exactly64 remaining
manifest-ordered IDs. No historical orbit or unproved skip is inferred.

Reconstruct the entire parent selection from the explicit request and verified
literal proof union. Reconstruct all four16 partitions, including parent pins,
indices, offsets, and the source's declared reason. Check the exact launch-plan
schema, four workers,120-second budgets, distinct attempt IDs and fresh mutually
disjoint output directories. This is a prebuild check; already existing build
outputs are rejected.480 seconds is the sum of four allocations, not a global
120-second execution guarantee. Backend engineering remains separately reviewed.

Authenticate the actual selector summary, command, source/spec pins, all input
and output hashes, all seven original output identities, recorded commit
provenance, and the complete saved prior-proof identity table. The recorded
commit is caller metadata, not a current Git query. No source is executed to
derive expected output. Raw model/CNF construction and new proof replay are not
part of this preparation gate.

Controls include all N1..64 prefix sizes and reversed skip order from the
independent helper, invalid types/bounds/skips, strict partition controls, and
mutations of the actual request, parent, four partitions and launch plan.
Compare complete canonical JSON structures so booleans do not substitute for
integer fields. Scope of positives is metadata/identity only.

Allocate120 seconds for one complete identity review. Save failures and do not
retry or overwrite. Outputs contain independent prior-proof records, controls,
and a summary with exact input pins, derived prior/remaining counts and selected
indices. Status INDEPENDENT_EXACT_EIGHT_PREFIX64_SELECTION_PREPARATION_PASS
does not approve a formula, native launch, new exclusion, fibre expansion, or
universe conclusion. Root authorizes every later build and solver allocation.
