## Independence and exact model

The checker never imports, AST-selects or copies a producer function. It builds
canonical [type index,copy number] labels directly from the strict integer counts.
Its pair ordinal is x*(2*n-x-1)//2+y-x-1, independently of the producer's pair
dictionary and incident append loops. It collects endpoint-variable sets, sorts
their ordinals, and separately constructs each degree and coordinate row.

For every copy x, the degree RHS is k-|T_x|. For every support u the coordinate
RHS is 2-1[u in T_x]-|N_H(u) intersect T_x|. The same unordered binary variable
occurs at both endpoints. All same-type and unequal-type distinct-copy pair bits
are checked; an empty diagonal list is harmless only without two actual copies.
No equitable profiles, target automorphisms, matching cuts, type filtering or
uniform local choices are assumed.

The raw model is compared recursively with strict type equality, preserving all
keys, label/pair order, variable bounds, every sparse coefficient and every row.
For the inherited fixed profile this is 472 masks,68 positive types,82 labelled
copies,3321 variables and1476 rows:82 degree and1394 incidence. Nine literal
checkpoints cover10,20,...,80,82 copies and contain the complete label prefix,
correct row/variable totals and the actual9876 ten-field deadline object.
Prefix and deadline type/flag/phase checks do not claim arbitrary forged clock
algebra or a hard-real-time theorem.

Candidate validation uses dense neighbor sets, not the saved sparse row evaluator.
It checks strict binary values, complete symmetric zero-diagonal D, vector/matrix
identity, all pair bits before all equations, every degree and support row in
copy/coordinate order. Exact independently calculated observations must equal
the producer's full exact row table. Bool and float are never accepted as ints.
