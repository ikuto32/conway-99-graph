## Exact numerical scope

The literal c628 model, 87d0 ordered type list and 50b complete cross-CN filter
are direct historical prerequisites. The checker reconstructs all 289 entries
of the literal twelve-row induced graph with neighbor sets, compares all model
header/support/154 row-label fields, reconstructs each of the 472 coefficients
from set membership and all unordered support pairs, and preserves the ordered
mask universe. It does not enumerate all 131072 masks again or rehash the
filter's 221-entry ancestor map.

For `U=3I-H+J/9` and `L=H+4I`, the checker builds integer-scaled matrices
`9U` and `L`. It directly multiplies each submitted inverse in both orders,
checking every 289 entry per side against the correctly scaled identity. It
separately checks every saved left/right product entry. It parses the submitted
unit lower triangular factor and canonical rational positive pivots and directly
checks every entry of `factor*diag(pivots)*factor^T`, with the proper scale.
It compares every saved matrix and reconstruction entry as well. It generates
neither an inverse nor an LDL factor for the target or for a submitted fixture.
The synthetic empty-graph certificates are supplied analytically.

All 472 records are recomputed with separate set-based masks, complete inverse
row sums, and full quadratic double sums. Every vector coordinate, canonical
fraction, upper/lower value and margin, boolean pass flag, and all four literal
equal-type bit lists must match exactly and with exact JSON types. The
equal-type rules refer to two **distinct** exterior vertices having the same
type: each candidate edge bit is tested by both 2x2 residual determinants and
the inside-support common-neighbor cap `|T| <= 2-edge`. This does not assert
two such vertices actually exist. All 14 completed 32-record blocks plus the
final 24 records must be byte-authenticated and typed-equal to the complete
already checked records. A final compact observation file retains every type.

## Bounded execution and limitations

All hashing, parsing, exact products, record checks, control execution, closing
input hashing and outputs occur inside one `CommandDeadline`, with a >20s save
guard before/after I/O and at matrix/type boundaries. The separately supported
Windows supervisor begins before locked offline UV. Proposed calibration is
180 outer / 150 worker / 20 save / 20 shutdown. A future full invocation requires
its own concrete plan, fresh admission and explicit ONE authority.

Files are restricted to the workspace, no symlink/reparse parent is accepted,
and an input file is capped at 64 MiB with guards every 1 MiB read. Scheduling,
an individual rational operation and filesystem writes are not hard real-time
services. Failure preserves completed fixture/output files and a best-effort
failure receipt; a hard kill need not save a pending suffix. A provisional
summary coexisting with a failure is not a gate. No automatic retry occurs.

Shared Python Fraction/JSON/SHA, deadline and supervisor components are
disclosed. Complete old ancestor evidence is not automatically rehashed. The
result is confined to the one fixed induced17 and its authenticated ordered
472 types. It proves no integer completion, graph realization, full family,
unequal-type pair census, optimality, target exclusion, or registry promotion.
Ledger, index and Git writes are outside this checker.
