# Streamed exact interval extension build

This is a new, authorized producer build using the immutable interval inventory configuration. It adds all 540 necessary coefficient-wise Gram interval inequalities to the frozen at-least-seven count-master CNF. It does not modify the baseline, inventory or prior source, and calls no solver. Output remains CANDIDATE until a separate implementation reconstructs the complete actual formula and calibrates a new object checker. The old count-master object gate is insufficient for this formula.

Exact expected output: 185,963 variables, 7,659,287 clauses, 163,409,055 ASCII bytes. The exact original at-least-seven body is the prefix after a new DIMACS header. The separately preserved suffix is 6,953,454 clauses / 152,147,616 bytes. All 8,244 OR channels and all 21,780 prefix states follow the immutable inventory order, masks, variable IDs and truth-table maxterms. A mismatch in any per-record or final count/byte total stops the build. No scalar interval shortcut is used. The root-verified 6,061-class extrema table and independent base encoding gate are mandatory direct inputs.

Allocation: 180 seconds cooperative wall time per invocation and 768 MiB process working-set ceiling where measurable. Source/spec and inputs are authenticated before emission. Files are streamed; only a single channel or counter record's short clauses are materialized. Progress is snapshotted after each 128 channels and 45 cells, with completed indices, cumulative hashes/bytes/clause counts, source/spec/input identities. The latest snapshot is also saved as checkpoint.json via a temporary file and atomic replacement. On timeout, save PARTIAL_UNKNOWN with partial-file hashes, never call it complete. A later explicit invocation may use --resume OLD_OUTPUT into a fresh output directory: authenticate old summary/checkpoint/all partial bytes and source/spec/input identities, copy and append only from that checkpoint. No automatic retry, no truncation, and no overwriting old partial/failure records. Other errors are FAILED and are not automatically resumable.

Before final names or a completion summary, compare actual prefix and suffix against the frozen input byte stream, verify full byte and clause totals, package the raw temporary files, and stream-recover every package byte. Only then rename temporary files to instance.cnf and interval.cnfpart atomically and save the model/scope/completion summary. An interrupted packaging attempt does not create a completed scientific result. Originals remain LOCAL_ONLY. Public transport uses independent deterministic gzip members over contiguous raw chunks of at most 9 MiB; each compressed member must remain strictly below 10 MiB. Filename is empty, mtime zero, level 6. Packages retain ordered offsets, raw and compressed hashes, lengths and whole-file recovery identities. This is transport verification, not proof checking.

The formula is only a count-table relaxation with a separately justified at-least-seven restriction and necessary scalar Gram intervals. It encodes neither full Gram simultaneous local realizations, cross-group column caps, nor residual D. No target automorphism or unconditional target existence/nonexistence is asserted. No ledger, index or Git changes.

Fresh command: `uv run --locked --offline --cache-dir .uv-cache-20260917 python -B acceleration/theory_20260930_count_interval_cnf.py --out acceleration/results/20260930_count_interval_cnf`

Explicit continuation, only after a PARTIAL_UNKNOWN record: same command with `--resume OLD_OUTPUT --out NEW_OUTPUT`.
