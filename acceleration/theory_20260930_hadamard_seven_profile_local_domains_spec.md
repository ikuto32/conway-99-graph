# Seven-exception local-domain filter

The frozen population is all 1,608 labelled necessary marginal profiles from the
38 nonempty cases of the completed 200-case seven-group DP. The producer summary
and independent DP gate are pinned by hash. Reconstruct every profile by exact
backtracking of the saved twelve layers, with no choice or case sampling. Check
each predecessor count and complete final count, literal kernel equations,
incident integer bounds, all 21 group-fibre quotas and exact activity mask 127.

For each of the seven exceptional groups in each profile, form its six-coordinate
ordered fibre-count signature and retain every matching local triple from the
complete pinned 31,110-entry cap-filtered catalog. All 150 balanced triples remain
available for each other group. Do not apply cross-group consistency, full Gram
or residual-D tests. An empty individual domain excludes only that necessary
profile with within-group overlap caps; nonempty domains do not give a factor.

This adapts the earlier six-group producer's backtracking/domain algorithm.
Sharing production logic is disclosed, not independent verification. Calibrate
with the balanced 150-option domain and a real unbalanced catalog entry, and
reject a changed coordinate count sum and count4. Any failed invocation preserves
its source hash and failure. Success requires all 1,608 unique profile hashes;
candidate conclusions await a separate implementation and controls.

Save every raw profile, complete local index lists, immutable per-case counts,
source commit, exact command/cwd, Python and locked environment/input/output
hashes. Global fibre permutation images are diagnostic only: no normalization
or exclusion coverage is asserted from these images. No target automorphism is
assumed and no whole-support or target conclusion follows.

Limit: 120 seconds, checked after each profile; no solver call. A failure or
partial output is not a complete census. Per-case records and profile prefix
are preserved, but this small deterministic filter has no resume CLI.
