SOURCE_ONLY and unexecuted. Producer is Native; independent verifier is
Checkpoint. Calibration and full mode need separate ROOT source/array review
and authorization. No producer helper or parser is imported, and no native,
scientific, ledger, index, Git, current-document or historical-state writes occur.

format dependencies. The scalar weight is577/1057/819820 for rook9/cube12/99;

recomputes all n squared products, diagonal included, independently of the
NumPy int64 path. No Native scorer, serializer or updater is called.

Calibration uses six positive records: rook9, cube12, explicit cyclic99 fixture,
synthetic complete-source/projection relation, synthetic supported outer

Full mode requires explicit SHA256 arguments for the applicable own calibration,
accepted complete Structural census, selected matrix/triples, actual producer
summary/plan and completed supervisor manifest/summary. It rehashes every
immutable calibration/census/producer/plan dependency inside the worker deadline.

a902/spec992a in its map, canonical Native-to-Structural artifact/NONE roles,
and direct selected raw matrix/triples pins. Its selected proposal must be
the first sorted minimum(F3,E) label. Census completeness is a prior explicitly
authenticated independent dependency; this conversion checker does not rerun
the census or infer any larger neighborhood.

Every target ordered row, the full9801 integer products and all4851 pair scores
are reconstructed, including both energy components and all three residues.
The wire is checked by the independent parser and compared with fresh exact LF
canonical serialization, including row order and the source matrix hash.

state/RNG/history flags. The actual directory and producer descriptors must
contain exactly invocation.json, graph_input.txt, projection.json, summary.json;
all three non-summary artifact bytes/hash/sizes are authenticated. The summary,
invocation and actual Linux supervisor must bind the exact project command,
euid1000, completed exit0, reaping and observed empty process group. This
checker launches no native code and approves no scientific execution.

parent traversal, external repositories, .git and CLAIMS.yaml. Hashing,
controls, reconstruction and output inventories share one CommandDeadline;

Historical HEAD/CLAIMS/index observations are checked before/after and stored

observations without pretending to change a mathematical source gate.

Limitations: one graph-only derivative of one already checked source selection;
no state/RNG/counters/history imported, no Native execution, full trajectory,
randomness quality, global minimum, performance, graph-space coverage or target
resolution. Shared Python/NumPy/hash/filesystem/runtime and earlier independent
components are disclosed in the report. Parent report inspection is separate
from this checker authoring or calibration.
