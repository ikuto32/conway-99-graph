## Logical equivalence, independently derived on paper

Three clauses (a or not z),(b or not z),(not a or not b or z) are equivalent to z=a AND b. Four threshold clauses express z=a OR (b AND c): the first two implications force z when either a or both b,c hold; the last two force a or b and a or c when z holds. Constant folds reduce these same formulas to a literal/constant or bidirectional conjunction/disjunction. Fresh auxiliary variables are monotonically allocated and each new gate depends only on earlier references, yielding exactly one auxiliary extension for any base assignment.

By induction on prefix i, threshold state s[i,j] is true iff at least j of the first i distinct input bits are true. State0 is true and out-of-range previous states are false. Emitting s[N,bound] and not s[N,bound+1] imposes exact equality. At bound0 the lower assertion folds to true; at boundN the upper assertion folds to true. An empty input vector with required0 creates no restriction; an adjusted bound outside0..N creates an explicit empty contradiction clause. The caller subtracts each fixed true term and discards false terms, preserving the original sum exactly. Degree/cross references are distinct base edge variables; different exterior witnesses cannot fold to the same free edge because z differs from both endpoints. The appended D[x,y] is a different edge. No accidental multiplicity is lost by the duplicate-input check.

The Traced subclass logs only newly allocated semantic gates. When recurrence's constant branch dynamically invokes conjunction/disjunction, the inner call logs the unique fresh gate first and the outer call does not log it again. Literal/constant folds allocate no variable. This explains the complete auxiliary-extension population assertion without asserting its executed success.
