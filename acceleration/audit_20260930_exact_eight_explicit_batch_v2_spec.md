# Independent explicit-batch encoding and object checker

Freeze this source/spec before any execution. This checker accepts one hash-bound
selection and a complete build summary containing 1..64 distinct cases from the
unchanged 792-case manifest. It never calls a native search, edits the registry,
or infers an exclusion from an encoding or a synthetic positive.

The initial supported allocation policy is FIRST_UNPROVED_PER_SELECTOR_SIZE_CLASS_V1.
Authenticate the independent complete domain inventory and all supplied completed
proof gates; bind every literal proof/CNF/scope/count identity and replay receipt.
Reconstruct the complete size distribution and choose the first not-proved case
in manifest order in each still-populated class, ordering classes by selector
count. Check the entire selection object, including all skipped IDs. A class
sample is never an exclusion or coverage result for other members of the class.
An unsupported policy is rejected rather than silently treated as equivalent.

Accept one complete explicit build invocation, or an explicit consolidation of
authenticated prefix invocations and separately authorized pending selections.
Check all commands, receipts, checkpoints and original case IDs. Preserve any
failed/partial invocation and never promote its unfinished child as a formula.
Independent frozen campaign functions reconstruct every local domain, count,
integer Gram coefficient, channel, counter and clause. This uses all initial
domains and within-triplicate caps; cross-group caps and residual D are omitted.
No producer or native Python module is imported. Reuse of the independent
next32 invocation-receipt function is disclosed; its main/selection logic is not
used. Every actual formula dimension is derived, never assumed to be 2184
selectors or 9748 variables.

Modes: audit --selection PATH --selection-sha256 SHA --batch-summary PATH
--batch-summary-sha256 SHA --out NEW; calibrate --encoding-gate PATH
--encoding-gate-sha256 SHA --native-driver PATH --native-driver-sha256 SHA
--native-spec PATH --native-spec-sha256 SHA --out NEW; sat --case-id ID
--encoding-gate PATH --encoding-gate-sha256 SHA --assignment JSON
--native-output LOG [--decoded JSON] --out NEW. Calibration and SAT recover the
exact selection/build pins from the approved encoding report.
Audit may also specify --claim-id for an editorial registry label; it does not
change the verified statement or selection. Without it a batch-hash label is used.

Controls include genuine SRG243 and reversed-column factors, exhaustive small
counter/channel relations, every actual dimension's full signed-assignment and
clause codec, malformed assignments/native status/literals, actual formula
mutations, domain/Gram/scope corruptions, and semantic selection mutations.
Synthetic codec positives and local-only positives are explicitly not research
factor witnesses. SAT requires every actual clause and exact integer raw factor
checks. Check all saved producer decoded fields when provided.

Audit/calibration allocation: at most 600 seconds for up to64 formulas; no solver.
The independent catalogue and existing checker functions are frozen premises;
the actual fresh native driver/spec and full static/dynamic runtime closure are
bound only during object calibration. Report fields include selection and build
paths/hashes, selected_case_ids, population_size, complete_formulas and checked_cases.
Any failure is saved in its newly created output folder; retries use new files.
