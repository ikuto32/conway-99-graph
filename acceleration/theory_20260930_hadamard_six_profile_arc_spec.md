# Six-exception labelled-profile pairwise screen

This is a new producer experiment. Its universe is all 984 literal profiles, in the order of the frozen `20260930_hadamard_six_profile_local_domains/profiles.jsonl.gz`. No fibre-orbit quotient is used. Each of the six groups retains its complete saved initial domain from the 31,110 local triple catalogue, including within-group Gram and column-cap conditions. Domain coverage is being independently reviewed separately.

Question: does pairwise compatibility followed by exact arc consistency empty any of those 984 six-domain instances? An empty domain excludes only that literal marginal profile under the fixed support, full prescribed integer Gram, and outside-column caps. A nonempty fixed point establishes only pairwise supports, not a joint six-choice solution, a full factor, or a 99-vertex graph.

The pair relation permits two local choices exactly when the sum of their two three-column Gram contributions is entrywise at most the prescribed 36-by-36 Gram and each of their nine cross-column intersections has size at most two. Save both the Gram-only and the combined relation. Diagonal pair contributions are bounded by six and hence below the target ten. For off-diagonals, retain exact masks for occupied target-one entries, occupied target-two entries, and twice-occupied target-two entries; check their equivalence with literal integer summation in calibration. No floating-point calculations are used.

First execute inventory mode. Authenticate all inputs, every raw domain reference and its exact local catalogue rank list, then freeze distinct `(group, domain hash)` endpoints and unordered endpoint-pair relations. Report all 14,760 profile pair uses separately from unique relations and unique option-pair products. Estimate cache memory conservatively from distinct lifted choices and relation bit tables. Do not start the research screen if the estimate exceeds 512 MiB, if a domain exceeds 150 choices, or if more than 50 million distinct option pairs would be examined. Inventory has a 30-second cooperative limit and launches no solver.

Research screen: one cooperative 120-second allocation including input authentication and fresh controls. Compute every distinct relation in deterministic first-use order, save immutable compressed tables, then process profiles in original order. At complete-relation and complete-profile boundaries, honor the wall cap and emit a resumable checkpoint. A single boundary unit can exceed the cap slightly; record actual elapsed time. Do not silently drop a case or promote incomplete work. `COMPLETE` requires all frozen relations and all 984 profiles; otherwise state `PARTIAL_UNKNOWN` with exact completed and pending populations. The checkpoint binds source/spec, inventory, all completed relation/profile artifacts and their hashes. Explicit resumption uses a new output directory plus the exact checkpoint hash; it never edits prior output. No automatic resume or native solver invocation.

Arc consistency uses fixed lexicographic ordered group pairs and increasing local-option indices, repeatedly deleting a choice only when it has no current support in its neighbor domain. Save every deletion with the current neighbor-domain mask. At a nonempty fixed point, save one explicit surviving supporting choice for every ordered arc and each surviving source choice. Raw profile IDs/hashes, six domain rank lists and relation hashes remain available. Counts distinguish relation products, profile attempts, complete profiles, empty profiles and unresolved profiles.

Controls run before research: genuine nonempty SRG243 factor-column pairs with its own exact Gram; duplicate-column and changed-Gram-mask corruptions; literal versus packed-mask agreement on deterministic actual-domain pairs; synthetic six-domain AC positives and contradictions, an exhaustive binary-domain triangle control proving AC never removes any actual joint solution, and malformed support/deletion controls. SRG243 is a different-parameter calibration, never a Conway99 positive. The producer is not its own independent approver.
