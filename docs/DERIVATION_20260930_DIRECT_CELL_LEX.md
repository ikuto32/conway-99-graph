# Candidate equal-support column ordering

This is a candidate normalization of the two frozen direct-cell formulas on the literal six-prism core and saved Hadamard support L. It is not a new support normalization for arbitrary target graphs. Both input formulas encode the prescribed full Gram matrix and every outside-column overlap cap. The count-coupled input additionally requires at least seven unbalanced support groups; that condition and its existing coverage premise are unchanged.

There are twenty distinct sorted supports, each occurring at three labelled outside columns. Write the selected fibre at each of the six support coordinates as a word in {0,1,2}^6. The column margins require two occurrences of each fibre. Two identical words have column overlap six and violate the existing cap two, so the three words in a group are distinct.

For any factor satisfying the input semantics, independently sort the three words in each group. If sigma[d] is the old column placed at new position d, then F'[:,d]=F[:,sigma[d]]. This permutation preserves L, all row sums and Gram entries, all column fibre margins, every overlap cap, and all mixed cap values up to the same column permutation. The counts across each triplicate group are unchanged, including its balance status and every count-master choice. Conversely, a sorted factor is an input factor by forgetting ordering. Thus satisfiability is equivalent, and the normalized semantic domain consists of the lexicographically ordered representatives under S3^20 on these column labels. Auxiliary SAT variables are recomputed from their exact defining relations; no literal permutation of the prefix counter graph is presumed.

This is a relabelling of a solution, not an automorphism of an unknown graph. If a residual adjacency D later exists, put D'[d,e]=D[sigma[d],sigma[e]]. With the corresponding column permutation matrix Q, F'=FQ and D'=Q^T D Q. Then FD=H becomes F'D'=HQ, and D^2+F^TF=kI-D+2J becomes the same equation after conjugation. Inverse sigma restores the original labels. No residual adjacency is encoded here.

The extension compares only the two adjacent pairs in each sorted triplicate: forty comparators. For words x,y, let e[p] mean x[p]=y[p]. These six flags already occur in the audited within-group cap encoding and are equivalent to equality under its two one-hot fibre triples. At position zero, forbid the three choices x[0]>y[0]. At position one use e[0] as a guard. For positions two through five add four exact AND gates with p[j]=e[0] AND ... AND e[j-1]. For each position j and each of the three fibre pairs f>h add the clause forbidding p[j] AND x[j,f] AND y[j,h], omitting the guard when j=0. This is exactly weak lexicographic order: the first unequal position cannot be an inversion, while positions after an earlier strict increase have false guards. Equality is allowed by this comparator but already forbidden by the existing column cap. It therefore imposes strict order on feasible input columns without extra pruning.

Each comparator has four new variables, twelve AND clauses and eighteen inversion clauses. Forty comparators add 160 variables and 1,200 clauses. The input CNF body is copied verbatim with only its header replaced, then the ordered suffix is appended. Production records every existing equality flag, primary cell, new prefix state and exact suffix clause. No base formula, source, gate, count table or native runner is changed.

Calibration enumerates all 90 squared balanced word pairs and all sixteen assignments to the four new variables, proving unique auxiliary extension precisely for the lex-allowed pairs. It includes equality, reversals, corrupted prefixes and omitted guards. A genuine (243,22,1,2) fixture supplies sixty triplicate groups of identical aggregate supports; column sorting and residual-D conjugation are checked by exact integer block identities, with malformed permutations and changed factor/residual entries rejected. This is a control in another parameter set, not a known factor on the research support. All build results remain candidates until a different reviewer authenticates the source, semantic scope and actual clauses.
