# Independent saved two-star and outside-domain audit

This audit concerns finite saved partial graphs, not a target graph or an
exclusion of any target family. No nontrivial target automorphism is assumed.
The checker imports no producer code and uses exact standard-library integers.

## Raw graph scope

Root labels are independently generated by a pair of distinct coordinates from
seven matched pairs, followed by their two signs. The checker reconstructs the
root scaffold's 189 edges, both quota-compliant twelve-label center stars, and
the sixteen declared matching additions. It compares this 228-edge graph entry
by entry with each saved 99 by 99 raw matrix. It checks all 99 degree caps and
all 4,851 common-plus-adjacency caps directly by neighborhood set intersections.

The center vertices are u=15 and v=59. Their common neighbor w and the two
twelve-element fibers A=N(u) minus {v,w}, B=N(v) minus {u,w} are reconstructed.
The final induced blocks A, B and A--B are perfect matchings. The two centers
have degree14. Exact common-plus-adjacency equalities are asserted only for
each center against the declared union of the 27 closed-edge-neighborhood
vertices and the root/14 inner vertices: 37 comparisons per center. An entry
zero in the known-edge matrix outside fully determined blocks remains a
potential target edge; the audit does not promote it to a target nonedge.

## Complete individual outside domains

For each of the selected four witnesses, all 61 outer vertices outside both
center neighborhoods are considered individually. The centers' degree14
neighborhoods are complete, so any target completion must give such a vertex z
exactly two neighbors in N(u) and two in N(v). The fixed inner incidences leave
deficits p and q. The only remaining possible contributions are the common
vertex w, ten outer vertices L in A and ten outer vertices R in B. Therefore
the complete individual universe is e in {0,1}, a subset of L of size p-e,
and a subset of R of size q-e. Invalid negative subset sizes give no cases.
No other target edge can change either centered common count. This establishes
coverage of each individual domain, not simultaneous compatibility of domains.

For each such choice the checker adds all selected edges z--T simultaneously.
Its checking path differs from the producer's sequential edge tests. Let
N_old be the original neighborhoods, and suppose the independently checked
base graph obeys all caps. For x distinct from z:

    common_new(z,x) + adjacency_new(z,x)
      = common_old(z,x) + adjacency_old(z,x)
        + |T intersection N_old(x)| + 1[x in T].

For x,y both different from z, the only changed common neighbor can be z.
The common count rises by one precisely when both x and y lie in the new
N(z) but not both in the old N(z). Their adjacency is unchanged. Thus the
checker tests all pairs containing z, and every pair in new N(z) having at
least one endpoint in T. Every other cap is unchanged. Degrees change only
at z and T. These identities establish that the optimized exact check is
equivalent to a full graph cap scan, for every enumerated pattern.

The code also exhaustively compares this delta predicate with literal whole
graph reconstruction on every cap-valid graph on five vertices, every center,
and every subset of its missing incident edges (with degree cap3). For every
real outside domain, one surviving and one rejected pattern are additionally
checked by literal full99 reconstruction. These controls do not replace the
complete domain enumeration or the identity argument.

## Scope and reproducibility

Run with the repository's unchanged locked environment:

```powershell
$env:UV_PROJECT_ENVIRONMENT='build/research-venv'
uv run --locked --offline --cache-dir .uv-cache-20260917 python -B acceleration/audit_20260930_joint_two_star_domains.py --out acceleration/results/20260930_independent_review/joint_two_star_domains
```

The output directory must be new. Input hashes, source commit, controls,
per-case and per-domain receipts, and exact totals are saved. A resource cap
failure leaves receipts but does not produce a successful summary. Coupled
search is not replayed; its saved resource-capped UNKNOWN status remains
separate and supplies no exclusion. Random generation attempt counts and
search performance are not independently verified by this audit.
