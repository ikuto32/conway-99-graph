# Independent direct-cell semantic review

This review concerns the frozen literal six-prism core and its saved12-by60 binary support L. It does not assert that an arbitrary Conway99 graph admits this L. It reviews the mathematical reduction and the root checker source without importing or executing either production or root-checker code. Complete clause reconstruction is a separate gate.

Write a row as (a,f), with coordinate a in0..11 and fibre f in0..2. Each support column contains one endpoint of each of the six coordinate pairs {2j,2j+1}. It has six coordinates. There are20 distinct supports, each repeated at three labelled columns. The direct cell x(d,a,f) exists exactly when L(a,d)=1. Exactly-one on its three fibres is equivalent to the binary aggregate-support identity. Exactly-two on the six cells of each fibre in each column gives the prescribed fibre margins. No column ordering, cyclicity, balance or automorphism is assumed.

The core consists of six disjoint triangular prisms: same coordinate across different fibres, and opposite coordinate endpoints within each fibre. Deriving the factor Gram from the raw39-vertex scaffold gives diagonal10, same-fibre nonmatched-coordinate entries1, different-fibre nonmatched-coordinate entries2, and all other off-diagonal entries0. There are540 positive upper-triangular entries. The90 omitted zeros consist of36 same-coordinate/different-fibre pairs, forced by exactly-one, and54 matched-coordinate pairs, forced by L. Exact AND products and the540 scalar equalities therefore cover every remaining Gram entry. Row sums10 give all36 diagonals.

For the standalone model these row sums are explicit. In the count-coupled model they follow from the selected complete coordinate count table. For any full-Gram F, let n(g,a,f) count its three columns in support group g. For every nonmatched b,

`sum_{g:a,b in S_g} n(g,a,f) = sum_h (FF^T)[(a,f),(b,h)] = 5`.

Also `sum_{g:a in S_g} n(g,a,f)=10`, and for each incident group the three fibre counts sum to3. Hence deviations n−1 satisfy precisely the saved bounded coordinate marginal equations. The independently checked complete coordinate census is the completeness premise; merely testing the saved tables would not prove it. This review rechecks every saved table's equations and its exact master binding.

Within a support group the three words each use every fibre twice. Their pairwise overlaps are at most2, so they are distinct. Each local Gram contribution is at most the prescribed global entry because all other contributions are nonnegative. Sorting the three words therefore witnesses membership in the complete31,110 local-triple catalogue, and its count signature is one of6,061 classes. This is a proof of membership only: the actual labelled F is never sorted. Each of its incident count triples belongs to the corresponding coordinate-channel projection. Thus its signature survives the master's unary filtering. The selected coordinate tables and group signatures agree on all channels and extend to the already verified master CNF. Conversely, master channels plus the conditional three-cell cardinalities impose exactly those raw counts; no missing selector can bypass them because the master channels are exactly-one.

It follows that baseline count coupling, explicit Gram constraints and within caps preserve exactly the corresponding raw F set. The built count≥7 variant additionally requires at least seven unbalanced groups. This restriction is stated separately and invokes the already checked fixed-support Gram-plus-all-caps lower-bound result. It is not silently inferred from Gram/within caps alone. No residual D is encoded. A count-CSP witness alone is not a full factor.

For two columns d,e, overlap equals the sum over shared coordinates of equality of their selected fibre labels. Under both one-hot fibre triples, the six flag clauses are equivalent to that equality: agreement implies the flag, while a true flag forces the second column's selected fibre to match the first. At-most-two flags is therefore exactly the raw overlap cap. Intersections of size at most2 need no clauses. This uses actual intersections, not the refuted0-or3 claim. The checker retains all1,770 column pairs.

Mixed caps are automatic for this literal geometry. Each column selects exactly one vertex from each six-vertex prism. A core row and its three core neighbours all lie in the same prism, so `F_i,d+(CF)_i,d <= 1`, stronger than the target-required bound2. This argument would fail for a different core/support; the raw matrices are directly authenticated.

Every satisfying semantic cell assignment extends to unique AND/flag truth values and the intended prefix-threshold values. Bidirectional recurrence `t(i,j) = t(i−1,j) OR (x_i AND t(i−1,j−1))` is justified by induction, with false unreachable states and true threshold-zero states. Exact cardinality requires both the lower threshold and the negated next threshold. Equality flags are not unconditional equivalences if one-hot premises are dropped; the audit saves an explicit falsification control for that misuse.
