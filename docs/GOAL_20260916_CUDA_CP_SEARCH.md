# CUDAによる候補ごとの近似再最適化

このページは7.316246→5.944366の保存済み記録である。その後のGPU改良と
最良配置の更新は [継続記録](GOAL_20260916_CP_CONTINUATION.md) に記載する。

目標は引き続き、独立検証済みの `srg(99,14,1,2)` の構成、または一般の
非存在証明である。今回もその目標には到達していない。

前回までのCUDA処理は、固定した補完変数Xで候補を採点していた。
今回の `overlap_cp_gpu.cu` は、候補ごとにXと双対変数を更新する。
Chambolle–Pock法を倍精度で実装し、行列を保存せず隣接関係から
行列積を計算する。候補の順位付けに使い、数値だけで候補を排除しない。
手法・入出力は `acceleration/CP_GPU_INTERFACE.md`、基礎検査は
`acceleration/CP_GPU_RESEARCH_NOTES.md` に記録した。

## 実装と独立検査

- Rust版の行列積、転置積、右辺は、5種類の配置について独立した
  99頂点モデルと厳密に一致した。2ステップの更新も有理数計算と比較した。
- CUDA版は保存済みCPU計算と短い独立再生を使い、720,720個の値を照合した。
  最大差は約3.89×10⁻¹⁵。目的値など620項目の最大差は約7.11×10⁻¹⁴。
- CPU/GPU共通の不正入力37種類、計74回をすべて拒否した。
- 行列は4,326行・1,680列・21,840非零成分。各列の成分数13、各行の
  最大成分数9から作用素ノルムの二乗を117以下と評価できる。
  刻み幅0.09で積は0.9477となる。これは収束条件の検査であり、有限回の
  浮動小数点出力を厳密な最適値に変えるものではない。

## 有限探索の結果

前回の最良配置（評価値7.3162464575）から、同符号マッチング1組全体を
変更する候補をRustで生成した。全14組の84,560通りには元配置の重複14件と
部分グラフ条件への違反11,307件があり、合法な候補は73,239件だった。
別のPython列挙でも全候補集合と交互サイクル分解が一致した。

`search_cp_matching.py` の保存済み実行は、次の順序で候補を評価した。

| 処理 | 対象 | 実測時間 |
| --- | --- | --- |
| Rustによる候補生成 | 73,239候補 | 約0.77秒 |
| 独立Pythonによる全候補検査 | 同じ候補集合 | 約23.58秒 |
| CUDA近似最適化・500反復 | 全候補と元配置 | カーネル42.20秒、呼出し全体46.27秒 |
| CUDA近似最適化・2,000反復 | 選択した2,048候補と元配置 | カーネル4.95秒、呼出し全体5.21秒 |
| HiGHSによるphase-I LP | 選択した64候補 | GPU処理を含む探索全体91.76秒 |

第2段階も同じ初期X/Yから開始する。500反復の途中状態からの継続ではない。
順位は初期値・最終反復・平均反復の主目的値の最小値で決め、組とサイクル形状の
多様性を残した。双対下界による候補の排除は行っていない。

64件中31件に数値上の改善があり、最良は候補59390の約5.944366122だった。
この候補の完全局所選択肢と頂点対整合性は独立に検査した。
全84頂点の選択肢を再列挙し、1,041回の削除と最終整合性を再生した結果、
13,424個の選択肢が残る。保存先は
`acceleration/results/20260916_cp_matching_search/local/index_59390`。

全64件のLPは独立した有理数計算で上下界を検証した。最良候補の厳密な区間は
**[5.944366121123388, 5.944366121993081]**、前回からの改善幅は少なくとも
**1.3718803354766993**。最良配置と証拠は
`acceleration/results/20260916_cp_matching_search/adopted_index_59390` に保存した。
全選択段階の候補順序・ハッシュ・順位・既評価193件の除外も独立監査済み。
選択した64件の最終反復と平均反復の目的値を99頂点から再計算し、3形状では
2,000反復を独立CPU実装でも再生した。

独立検証した正のphase-I下界を持つ固定配置は、完成グラフの候補としては排除される。
採用するのは、さらにマッチングを変更するための探索の出発点である。
この値は完成までの距離や達成率ではない。全候補のLPを解いたわけでもなく、
局所最適性、複数組の同時変更、異符号マッチング、全探索空間を覆う結果ではない。
