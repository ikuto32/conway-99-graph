This version adapts the public 54-profile object wrapper to the 215 frozen seven-exception formulas. It reuses root's separately authored and independently passed complete 215-profile reconstruction, including the seven-argument scope derivation with exact per-case selection path and hash. It does not import producer or native-runner code. The native runtime import closure is discovered statically and augmented with the explicitly dynamic balanced helper and both seven-profile producer specifications. The earlier first-seven producer was authored in this lane; the complete 215-formula encoding was independently approved by root before this object path reused that separate checking implementation.

Calibration authenticates all 645 CNF/model/scope artifacts, all 215 selected-profile records and every initial local-domain reference. It freshly reconstructs every scope, option catalogue, coefficient, auxiliary mapping and actual clause stream. Each profile receives first-option and last-option local-decode positives, with exact aggregate counts, row margins and within-group caps. These are local-only controls, not full-Gram factors. A complete first-option auxiliary assignment must be rejected by the actual full formula; any unexpected positive stops calibration for independent review.

Four distinct formula sizes receive complete synthetic native/JSON and clause fixtures: 9,872/170,454; 9,880/170,650; 9,898/171,091; and 9,952/172,414 variables/clauses. These are codec fixtures, not research SAT. Positive raw-factor checking uses the authenticated 243-vertex SRG-derived factor and a reversed-column image. Flipped entries, nonbinary/Boolean/ragged matrices, false clauses, missing IDs and malformed native streams are rejected. No genuine factor in one of the research profiles is presumed.

Actual SAT mode independently checks every signed native and JSON literal, every actual clause, the complete raw 36x60 incidence matrix, all 1,296 integer Gram entries, margins, literal count profile and canonical C0 reordering. It reports all 1,770 outside-column pairs and mixed caps as diagnostics; cross-group caps and residual D are not encoded. Optional producer-decoded bytes must agree with the independent object. The result concerns only its literal profile and this fixed support, with no target automorphism or full-target resolution claim.
