## Necessary-condition argument to review

For any graph with lambda=1, the induced neighborhood of every degree-14
vertex is exactly `7K2`: each neighbor has exactly one neighbor within that
neighborhood, namely its unique common neighbor with the center. This
requires no graph automorphism and holds independently of E0.

Let `P` be a partial graph of a hypothetical Conway graph, and suppose the
entire final neighborhood `N` of a vertex `u` has been selected. Let `F` be
the already present edges within `N`. Partial adjacent-pair common-neighbor
caps imply that `F` is a matching. Delete all endpoints of `F` from `N`,
leaving an even set `W`. In the current E0=0 model there are already two
forced edges involving the root labels, so `|W| <= 10`.

Construct an allowed-edge graph `H` on `W`. Include `v-w` precisely when it
is still an unfixed edge in the declared model and adding this single edge
to `P` violates none of its common-neighbor upper bounds. In a valid
completion, the remaining neighborhood edges form a perfect matching of
`H`. Thus **if H has no perfect matching, that selected complete star cannot
belong to any valid completion**.

The single-edge test is exact: adding `v-w` changes its own cap from two to
one; it increments the common-neighbor count of `w,z` for each old neighbor
`z` of `v`, and of `v,z` for each old neighbor `z` of `w`. No other pair
changes. Existing counts must therefore obey `CN(v,w) <= 1`, and each
affected other pair must have at least one unit of residual capacity.

The new producer enumerates perfect matchings by the exact recurrence

```text
M(empty) = 1
M(W) = sum[M(W \ {v,w}) : w in N_H(v) intersect W]
```

where `v` is the smallest remaining vertex. Each unordered perfect matching
appears exactly once. Zero is an exact failure certificate for this finite
graph, once its edge set and recurrence are independently checked.

A positive matching count only passes this relaxation. Distinct individually
allowed edges can jointly violate other pair caps. Matchings at different
centers can conflict, and neither graph construction nor sufficiency is
asserted. The historical domain definitions and star IDs were not changed.
