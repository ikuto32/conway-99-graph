# Independent completed-interval review

The finite domain is the authenticated four-exception profile screen on the
single fixed Hadamard support, with prescribed Gram upper bounds and outside
column-overlap caps. This review checks only the producer's saved completed
outer-choice intervals. A twelve-column partial object is not a full factor.

The previous independent gate authenticates every local option and pair
relation. This checker constructs each option's literal integer Gram
contribution from its three row sets, including all diagonal entries. It
packs the 666 upper-triangular counts into base64 integer lanes. For target k
in a lane, adding31-k and inspecting bit32 detects precisely count>k. Each
four-group count is at most12, so the largest lane sum is43 and no carry can
cross a lane boundary. This is exact integer arithmetic, different from the
producer's occupied/doubled masks. All 4864 two-lane bounded coefficient
cases and seventy genuine SRG243 four-group positives calibrate the path.

The enumeration forms compatible group(2,3) pairs first, then joins group
(0,1) pairs through every cross relation, checking triple and quadruple
Gram bounds separately. For each saved outer interval it derives the full
survivor set, reads every gzip JSON record, checks exact domain/catalogue
indices, rejects duplicates, and requires equality of the sets. Strict raw
record order and all intermediate stage counts are also checked. Checksums
bind every completed checkpoint and chunk, with no inference from a file
count alone. Explicit missing, added, duplicated, corrupted and truncated
record controls test the codec and coverage boundaries.

Cases0 through34 are complete within their frozen AC domains. Case35 is
checked only for its first three saved outer choices. Sixty selected
profiles are unattempted. Counts for the partial case are not promoted to
complete-case counts. The v1 genuine243 diagonal-limit control failure is
preserved; it occurred before the research enumeration. No solver is used.

All thirty-six first raw witnesses are independently decoded and checked
entry by entry against the complete Gram residual and every one of the66
column pairs. For each of sixty nonmatched coordinate pairs, the remaining
3x3 nonnegative matrix has the required common row and column sum. The
checker explicitly removes perfect matchings to exhibit a decomposition
into permutation matrices. These separate pairwise decompositions do not
assemble a common remaining48-column factor and say nothing by themselves
about its rank, PSD, column caps or residual graph.
