# Independent normalized coarse60 object checker

This wrapper binds the independent bit-flip normalization audit and the
original complete raw-factor checker. It reads all5238 native and JSON
assignment values and checks every one of85704 actual normalized CNF clauses.
It separately requires all six first-column raw bits to be zero. The frozen
independent local-mask decoder then reconstructs all360 component bits and
the raw36x60 factor. A complete canonical-C0 column bijection precedes the
full integer Gram, margin, mixed-cap, outside-cap and partial99 checks.

The wrapper imports only earlier independent checking paths, with their exact
hashes bound in the report. No producer decoder or solver is imported. The
original16 corrupted controls and known nonempty SRG243 factor control are
re-executed in a separate nested calibration directory. A normalized local
mask assignment tests the unit boundary and all native/JSON codecs against
synthetic5238-variable85704-clause data. This synthetic formula is explicitly
not the research formula, and its local factor is not asserted to satisfy
the research Gram. Fresh corruptions include each of the six required bits,
an actually false final unit, incorrect header and incomplete assignment.

The checker accepts `calibrate --out DIR` or `sat --assignment JSON
--native-output LOG [--decoded JSON] --out DIR`. Any SAT object remains a
factor for the fixed60-pattern template: residual D and a complete99 graph
are absent. A failed check cannot become an exclusion or an UNSAT proof.
