fixed six-prism Hadamard support. The separate coverage gate proves the global
three-fibre action on this fixed input and on every complete initial domain.
This audit composes these premises for their actual shared tables and formulas.

comes from row(p(f),a). The row permutation P preserves the literal core C and
prescribed Gram G. It sends the count table c to c'[a,g,f]=c[a,g,p(f)]. Within
each group the three columns have equal support, so a column permutation Q may
sort their transformed colour words. This sorting gives precisely the complete
domain used by the literal encoding: repeated words are disallowed by overlap6,
and a balanced triple's sorted first coordinate has colours0,1,2. Therefore

The maps are invertible, and no automorphism of an unknown target is assumed.
If a residual completion were present, D'=Q^T D Q would transport it as well;
no residual existence is used in the argument.
