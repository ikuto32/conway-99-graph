# Candidate exclusion of the unpaired five-matching cell design

This proof is producer work pending independent review. It concerns exactly
the thirty cell patterns from the five round-robin perfect matchings of K6,
each repeated twice. The six bit choices in each of the sixty columns are
unrestricted. The six-prism core is fixed; no target automorphism or
universal containment is assumed. A timed-out SAT run is not a premise.

## 1. Eighteen exact systems

For component a and cell g, let T_ag be its ten matching/cell patterns. For
each t in T_ag put `u_t=x_(2t,a)+x_(2t+1,a)-1`, an integer in `{-1,0,1}`.
The prescribed pair-bit counts imply, for every other component b and cell h,

`sum_{t in T_ag: cell(t,b)=h} u_t=0`.

Indeed the bit-a sum on that domain equals its number of patterns: each
of the two joint values with a-bit one is required once per same-cell domain
or twice per distinct-cell domain. There are two or four patterns respectively.

The accompanying raw15x10matrices use these fifteen equations as rows and
the ten sorted pattern indices as columns. For all eighteen choices(a,g),
the candidate exact reduction has rank nine and a one-dimensional nullspace
generated by a vector v whose ten entries are all `+1` or `-1`. Every rational
row operation and transformation is saved. The rank assertion is finite and
is to be established by independent replay of all eighteen certificates.

Given that assertion, u=sv. One coordinate of v has magnitude one, so
the corresponding u coordinate forces `s in {-1,0,1}`. If s=0, the two bits
in every repeated pattern are complementary. If s is nonzero, every pair
sum is zero or two, so the bits in every repeated pattern are identical.
Call these the complementary and identical types for(a,g).

## 2. At most one identical component per cell

For different components a,b and a fixed cell g, exactly two of the thirty
patterns put both components in g; the artifact checks all45populations.
If both(a,g) and(b,g) have identical type, then each of the two repeated
patterns contributes two identical bit pairs. Every count of00,01,10,11 in
the four columns is therefore even. The prescribed Gram instead requires
each count to be one. This contradiction allows at most one identical
component for each of the three cells.

Thus at most three distinct components have any identical-type cell. At
least three of the six components are complementary in all three cells,
and hence on every repeated pattern pair, whatever cell the pattern chooses.

## 3. Three complementary components are impossible

For any different components and fixed bit values, summing their prescribed
Gram entries over all nine ordered cells gives `3*1+6*2=15`. Because each
column has one row from each component, this is the exact joint bit count.
In the full sixty columns the two components therefore differ in thirty
columns. Select the first copy of each of the thirty patterns. For any two
of the three fully complementary components, the second copy complements
both bits and preserves their disagreement, so their representative words
have Hamming distance fifteen.

For three binary words, at each coordinate the number of disagreeing pairs
is zero or two. The sum of their three pairwise Hamming distances is even,
whereas the required sum is45. This is a contradiction.

Subject to independent verification of the saved finite rank certificates
and the stated implications, the entire specified unpaired cell-pattern
family is excluded. This is broader than the preceding globally
complement-paired design, but does not exclude different cell patterns,
arbitrary factors for the six-prism core, or Conway-99.
