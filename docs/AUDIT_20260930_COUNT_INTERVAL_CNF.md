# Independent scalar Gram interval encoding

The original >=7 count-CSP body is preserved byte for byte. For each selected group count signature, let l and u be the exact minimum and maximum of one local Gram coefficient over the whole corresponding local-triple domain. The root's separate complete interval audit establishes these extrema and their coverage. They lie in {0,1,2}. Consequently l=[l>=1]+[l>=2], and likewise u. An exactly-one signature domain makes each threshold indicator the OR of the selectors whose exact extrema pass that threshold.

The new clauses give both directions of every such OR. Empty, full and singleton subsets can be replaced respectively by false, true and the single selector because exactly one signature is selected. Sharing is permitted only for identical group IDs and exact selector subsets. The audit independently reconstructs all 10,800 requested subsets from the raw extrema and authenticated domain maps, not from producer masks, including all actual omissions and sharing. No producer code is imported.

For every one of 540 nonmatched-coordinate/fibre Gram entries, the five group contributions must sum to the exact target. Thus sum l <= target <= sum u is necessary. Ten Boolean indicators represent each side exactly. The bidirectional threshold recurrence is the already independently checked logical relation, now with repeated or constant inputs allowed; complete truth-table clauses cover every such valuation. Requiring NOT threshold(target+1) gives the lower-bound-sum cap; requiring threshold(target) gives the upper-bound-sum floor. This is exact encoding of these scalar interval inequalities, not simultaneous realizability of all Gram entries.

The checker reconstructs all 8,244 OR channels and 21,780 prefix auxiliaries, every clause and metadata byte range, all base/suffix bytes and all ordered gzip transports. Tiny exhaustive OR controls use arbitrary assignments, not merely one-hot inputs; prefix controls cover repeated and constant inputs and flipped states. The base and extrema proofs are reused premises, explicitly separate from this new complete encoding check.

This necessary relaxation omits unsummed full Gram, cross-group column caps and residual D. It makes no target automorphism assumption and no target-level existence or nonexistence claim. A constructed satisfying assignment is a count profile only. No solver is called in this audit.
