# Independent explicit-batch native outcome and complete-proof review

This reusable checker accepts a terminal campaign summary and its exact hash,
plus independent encoding/object report paths and hashes. The reports determine
the literal selection and complete build summary. Require 1..64 distinct cases;
use actual per-case dimensions. The native source/spec and object checker are
frozen to the generic explicit-batch versions, with all source/input/tool pins.
Prior skipped proof identities are an authenticated premise of the encoding
gate, not new attempts or new exclusions in this run.

For every attempted prefix member, verify source-bound allocation, command,
native version and statistics, exact CNF/model/scope/count identity, raw receipts,
saved targeted process observations, ext4 creation and prelaunch resource
receipts, immediate transfer and full host trace bytes. Authenticate each
checkpoint, exact pending suffix, stop reason and cumulative accounting. Do not
query unrelated processes or claim current ext4 availability from a historical
transfer. Unknown trace size remains unknown, not zero.

Native limits are60 wall seconds,1,000,000 configured conflicts,4GiB address
space,256MiB trace file, seed0 and70-second outer guard per attempt; selected N
allocates60*N seconds. The generic runner ceiling is64 attempts,64GiB aggregate
artifacts,32GiB host reserve and2GiB ext4 reserve. There is no automatic retry or
resume. An actual small conflict overshoot, if any, is reported as observed and
not rewritten to the configured value.

UNSAT requires a complete independently replayed DRAT proof for every claimed
literal case. Reuse the frozen independent DRAT authentication/replay helper and
its pinned DRAT-trim/Windows shim/compiler provenance, explicitly disclosed.
Run fresh satisfiable/unsatisfiable truth fixtures, valid and corrupt DRAT
controls, changed-input rejection, and receipt/status/header mutations. Complete
proofs only; no sampling. The checker never launches CaDiCaL.

For SAT, independently parse every signed native/JSON variable, reconstruct all
actual clauses, decode the exact36x60 binary factor and verify full integer Gram,
counts, canonical first-fibre transport and within-triplicate caps. Cross-group
caps remain diagnostics; residual D is absent. Verify optional producer decode
literally. A SAT factor or UNKNOWN stops expansion and is not a target verdict.
UNKNOWN, unattempted and unverified cases receive no mathematical exclusion.

Only a fully replayed all-UNSAT selected batch receives the aggregate exclusion
binding. Otherwise save exact checked individual outcomes and the pending list;
do not claim the entire selection excluded. Explicit case IDs prevent overlap
with prior skipped cases; other historical/fibre-orbit unions remain separate.

CLI: --campaign-summary PATH --campaign-summary-sha256 SHA --encoding-gate PATH
--encoding-gate-sha256 SHA --object-gate PATH --object-gate-sha256 SHA
[--claim-id ID] --out NEW. Freeze source/document before execution, wait for the
terminal hash, preserve all failures. At most64 complete replays, each with the
calibrated180-second checker guard; no solver allocation is requested here.

Both supplied independent reports must bind those exact bytes and the same complete static checker import closure, whose repository modules must be audit helpers rather than producer/native modules. Every closure hash is checked before a possible SAT-path import; the actual native invocation must name this exact checker. The native driver/spec, resources, formula semantics, complete DRAT path and outcome classification are unchanged. The original auditor remains frozen. Source is prepared without executing gates or native search; the declared selected64 campaign remains a separate later invocation.
