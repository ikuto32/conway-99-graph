# Independent local-signature Gram interval audit

Before execution, root fixes a 180-second audit allocation, with no native solver call. The producer is `/root/eight_domain_audit`; the checker imports none of its code. The complete previously checked local catalogue and literal support are explicit premises.

The checking path rebuilds all local count classes from binary 18-by-3 column matrices, computes their full Gram matrices by exact int16 products, and reduces minima/maxima with indexed NumPy operations. It verifies every saved coefficient and extremal witness. Global checking embeds each group's complete local lower/upper matrices into 36-by-36 arrays and sums them, independently of the producer's per-cell incidence summation. It checks every saved bound, violation and term for all 984 frozen profiles.

For any actual factor, each group's local triple belongs to its selected count class. Each scalar Gram contribution lies between that class's complete minimum and maximum. Adding the inequalities over all groups proves necessity of the bounds. These separately attained extrema need not be jointly attainable, so interval survival does not imply factor existence. No symmetry assumption is used.

Controls include every choice in several finite product domains, deliberately narrowed and shifted bounds, the balanced count table as a relaxation positive, malformed extrema/witnesses and corrupted profile/coverage records. The balanced count table is not asserted to lift to a factor. This audit does not establish a new whole-support exclusion; all 984 calibration profiles already have a stronger independently checked exclusion.

All arithmetic is exact: binary local products sum at most three and global entries at most sixty, within int16 range. Standard Python, NumPy and raw data are shared trusted components; the producer's bit-mask implementation is not imported. The report binds exact source, input and output hashes and contains the actual command and elapsed time. No ledger is changed by the audit.
