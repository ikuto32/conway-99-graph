# Necessary matching filter for eight-coordinate stars

Preregistered before filter execution. Proceed only after the separate full
84-center domain audit is bound to the exact 2,290,122-choice input universe.
Family: 120 fixed baseline K edges and all prescribed absences retained;
2160 unknown edges. No automorphism assumption.

Question: which locally admissible center stars fail the necessary condition
that their full 14-vertex neighborhood can become seven disjoint edges? For
each center in ascending order and each original domain ID, keep forced edges,
form the graph of individually permissible unknown edges on unmatched vertices,
and count perfect matchings by the frozen exact producer recurrence. Reject a
star precisely when this count is zero. Keep original IDs, full raw witnesses,
and the exact rejected/surviving partition. Positive matching existence is
necessary only: combinations of those edges may still conflict globally.

Before processing, run known-valid matching, missing-edge, K10 count, windmill
and corrupt-cap controls. Independent verification must reconstruct allowed
edges by graph mutation and check each rejection with a different edge-based
subset DP; check surviving witnesses directly. All original choices must be
accounted for. No sampled verifier may establish the whole filter claim.

Resource limit: 600 seconds per invocation, exact integer arithmetic, no
randomness. Preserve completed centers and partial-center records on a cap;
continuations use the same frozen inputs with a new output directory and an
explicit checkpoint. No LP is launched by this program. Empty domains are
candidate conditional exclusions only after the separate full audit. Any
further model construction or numerical solve has a separate audit gate and
resource protocol. Compress large records losslessly; preserve raw originals.

The first frozen-weight transfer screen has already produced a CANDIDATE
84-star witness against positivity of that one vector; this motivates new
optimization after these gates, not a feasibility or exclusion claim.
