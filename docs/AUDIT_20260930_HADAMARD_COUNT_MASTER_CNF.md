# Independent count-master encoding audit

This audit uses no producer imports. It authenticates the earlier independently checked complete coordinate domains and local-signature unary filtering, reconstructs every literal local signature, then independently allocates all selectors, count channels and auxiliaries and compares every actual clause and every metadata range. Reusing those authenticated domain-completeness results is an explicit premise, not a new independent enumeration of their whole finite universes.

For a nonempty exactly-one domain, the positive clause supplies a selected item. The sequential prefix clauses prohibit any later selected item once an earlier item is selected. Conversely, a single selected item satisfies them by setting every prefix to whether its prefix contains that item. Under exactly one selection this prefix assignment is unique: before the selected item a true prefix would propagate to its predecessor and contradict its exclusion clause; afterwards the true selected item forces all subsequent prefixes. Each coordinate and each group chooses one table row. Every such selector implies its count value at each incident coordinate/group channel, and that channel is exactly one. Thus the two chosen descriptions agree if and only if all implications are satisfiable. A compatible joint count table conversely selects its coordinate rows, its unique count signatures and its channel values. This proves exact encoding equivalence for the declared count CSP, not full-factor equivalence.

Every group has one and only one all-ones count signature. Its selector is true exactly when that group is balanced. Therefore at least seven exceptional groups is equivalent to at most thirteen of these twenty selectors. The appended recurrence is t(i,j) = t(i-1,j) OR (b_i AND t(i-1,j-1)), with true threshold zero and false impossible thresholds. Induction on i proves its intended meaning. The complete forbidden truth-table rows establish both directions of each recurrence. Requiring NOT t(20,14) is the exact bound. The previously independently established at-most-six exclusion makes this necessary for a full factor on this literal support satisfying full Gram and all outside-column caps. It is not a consequence of the unbounded baseline CSP.

The checker tests exhaustive tiny exactly-one assignments, every truth row of every actual threshold gate, two authentic complete baseline count assignments, their failed >=7 extensions, and deliberate clause/header/order/assignment corruptions. These count-table positives are explicitly not full factors or target graphs. Whole gzip recovery is checked separately as byte transport, not mathematics.

The model omits unsummed full-Gram equations, cross-group outside-column caps and residual D. A SAT assignment establishes only the decoded finite count profile. UNSAT requires a complete independently replayed proof for the exact input before any conditional exclusion; this encoding audit invokes no solver.
