# Independent object path for the six forbidden count profiles

This checker reuses the frozen independently authored native and CNF parsers from
`audit_20260930_hadamard_count_master_object.py` and its independent raw count
decoder. It imports no producer, solver runner or cut-discovery implementation.
The separate root encoding gate establishes the six cuts' mathematical necessity
and exact byte composition; this object gate binds that premise and checks the
actual supplied object against every clause and raw count condition.

The full155939-variable signed JSON model must exactly equal the complete native
SAT v-lines. The strict native parser rejects incomplete/duplicate/out-of-range
IDs, missing termination and conflicting status. The actual fresh CNF has705839
clauses; every clause is evaluated. Raw count decoding then checks the original
coordinate/group one-hot choices, incidence consistency, marginal equations and
local signature witnesses. The object has at least seven exceptional groups.
For every forbidden profile, equality of the full count table must agree with
equality of all twenty group selectors, and the negative20-literal clause must be
equivalent to avoiding that table.

The frozen native driver still uses the original producer decoder on the old
705833-clause model. If its optional decoded artifact exists, its old clause-count
field is compared honestly against705833. The independent new-formula check is
reported separately as705839. No omitted six-cut check is attributed to the old
producer decoder.

Calibration uses all six saved transformed count assignments. Each satisfies all
old705833 clauses and independently decodes, while its own new cut is false and
the other five are true. Thus these are genuine old-CSP positives and deliberate
new-formula negatives. Two authentic baseline count objects are positives of the
cut layer only. A small complete base-plus-six-suffix formula provides a positive
full-clause control. Full-size native codec fixtures and native/assignment/CNF/
decoded-table/cut-sign corruptions test rejection. No new research SAT result is
fabricated for calibration, and no native search runs in this checker.

Any eventual PASS certifies one count-CSP witness outside those six tables. It
does not certify unsummed full Gram, interval constraints, outside-column caps,
a binary factor, a residual completion or Conway99. The root's mathematical gate
and all shared parser/decoder/source trust are explicit in the recorded inputs.
