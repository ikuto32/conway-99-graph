literal artifact hashes; there is no arbitrary-core input path. Each new-core

resume_regression and main changed, with bind_portfolio added. The canonical

native invocation and all engine helpers are identical. The source diff is

resume check, and extend bounded calibration to the four new IDs. Native

The reviewer executes a fresh actual public portfolio calibration. Both the
original and fresh twelve-call GPU populations are then checked by an
independent implementation: every proposal/RNG/acceptance/state update uses
full columnwise integer objective recomputation. Each saved CPU whole run
must match all GPU chain fields. Disk23+41 and whole64 trajectories must agree
in every persisted final field and all concatenated trace entries. Literal
raw factor validation independently checks exported initial/current/best
matrices and the fresh stage endpoints. The exact known243 positive and a
malformed raw factor also calibrate the reference path.

including split repeats; each has512 CPU repeats. They are finite controls,
not independent construction searches. There is no campaign, speedup,
universal floating-trajectory, full-factor or Conway99 conclusion. Every
future campaign requires its own saved-object verification, and score zero
