# Independent native count-profile checking

The wrapper imports only the frozen independent complete-encoding checker. Its parser and complete actual-CNF reader are separately written here; the raw table checker is explicitly shared with the independent encoding audit. It never imports the producer, native runner, solver or producer decoder. Authenticated model rows are accepted only through the complete encoding gate, whose raw-input hashes are checked again. Native source and complete runtime code/spec closure are hash-bound for the launch gate; this does not imply a solver execution has occurred.

SAT checking requires exactly one SAT status, complete unique native and JSON signed assignments, their literal equality, and satisfaction of every actual clause for the specified baseline or augmented variant. It independently selects the twelve coordinate profiles and twenty local signatures, checks all 720 bounded integer entries, absent supports, each group's fibre totals, all summed marginal equations, every channel agreement, and the exception bound when requested. Optional producer-decoded fields must match the independent result exactly, with JSON types preserved. Output is an integer count profile and local possible triple lists; it is not an incidence factor, residual graph or target graph.

Calibration uses the two authentic complete baseline count-CSP assignments, including all 704,454 actual clauses each. Their recomputed augmented thresholds correctly reject both because they have fewer than seven exceptional groups. A 155,939-variable native stream is a codec-only fixture; it is not described as satisfying the research CNF. Tiny actual-CNF positives and native streams exercise corruption controls; assignment, selector, channel, prefix, count table, header, unit, missing-clause and native-status failures must be rejected. No research solver is called by this checker.

Actual ABI: `sat --variant at_least_seven --encoding-gate PATH --encoding-gate-sha256 HASH --assignment JSON --native-output LOG [--decoded JSON] --out NEW`. The baseline variant remains available for controls and exact table witnesses. Both variants retain their different scopes. The augmented bound is necessary only for the fixed support full-Gram family with all outside-column caps, by the explicitly pinned earlier exclusion.
