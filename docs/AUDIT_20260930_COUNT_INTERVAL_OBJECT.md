# Independent constructed interval-count witness

This checker accepts a complete strict signed assignment and checks every actual clause of the exact 185,963-variable 7,659,287-clause formula. It reuses only the frozen independent base count decoder and native codec. It decodes the original coordinate and signature choices, checks all count equations and the at-least-seven bound, then independently derives every one of the 540 interval sums from raw signature extrema and the prescribed Gram reconstructed from the raw cubic core. Every OR value is compared with its selected-signature membership and every threshold auxiliary is compared with a direct prefix count rather than a recurrence execution.

The `constructed` mode requires no native log. For the frozen supplied construction it checks that the first 155,939 variable values exactly retain the previously independently checked native SAT assignment. It also checks the producer's zero-native-call record, raw profile and all interval records. The mode is labeled a constructed satisfying assignment, never a native SAT result. `sat` mode additionally requires actual native output, while its parser and clauses remain the same. No solver is launched by any mode.

Calibration uses this full authentic constructed count witness as a positive, checks every actual clause, and saves explicit false actual clauses after flipping coordinate/group/OR/prefix values. It rejects malformed assignments and invalid native streams. A synthetic complete native-format stream is clearly codec-only and never claimed to be solver output. Exact formula reconstruction is a separately pinned gate. Shared source and the unused native wrapper/engineering closure are authenticated and disclosed.

The witness demonstrates satisfiability of a necessary count-and-scalar-interval relaxation. It does not supply simultaneous local triple choices, full Gram, cross-group caps, residual D or a target graph. Neither its eight exceptional groups nor its scalar bounds imply feasibility of a full lift.
