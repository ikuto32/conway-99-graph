# Cyclic-factor complete object checker

The checker pins the independent complete encoding gate and literal CNF, model,
scope and support. It requires all26360 assignment IDs exactly once, matching
complete native DIMACS output, and checks every122394 actual input clause.
Twenty selected choices expand to sixty original-order columns directly from
coordinates and colour phases. The expansion is independent of producer saved
row masks and decoder routines.

The independently authored noncanonical factor path verifies the complete
canonical-C0 column bijection and inverse, all1296 integer Gram entries, margins,
all1770 outside-column caps and the fixed literal coordinate support. The
optional producer decoding is compared field by field, including the canonical
column permutation. An accepted object is a partial factor, never a completed
99-vertex target graph. Residual D remains absent.

Fresh calibration uses the independently validated nonempty243 construction,
including reversed column order; it is explicitly outside the research99 scope.
Local cyclic choices test expansion and are rejected by the full research
constraints. Synthetic full-size clause and native files test all IDs and
boundaries only, not satisfiability of the research formula. Damaged matrices,
scope, assignments, native terminators, clauses and choices must be rejected.

Run the locked Python command with mode `calibrate --out NEW_DIRECTORY`, or mode
`sat --assignment JSON --native-output LOG --decoded JSON --out NEW_DIRECTORY`.
Inputs and all shared independent helper sources are hashed in each receipt;
no producer code or solver is imported or executed.
