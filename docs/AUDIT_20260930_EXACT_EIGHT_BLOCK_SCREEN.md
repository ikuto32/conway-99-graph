# Independent separate-block review

This document specifies the mathematical argument used by the independent checker. It does not assert a result before the executable audit passes against authenticated completed inputs.

Fix two nonmatched coordinates a,b. The literal support contains exactly five groups carrying both. A group consists of three outside columns with the same six-coordinate support. For a local triple, let U and V be the3-by3 binary incidence matrices whose rows are fibre labels and whose columns are the triple's three columns, at a and b respectively. That group's contribution to the cross-coordinate Gram block is `UV^T`. Its nine entries are nonnegative integers. Summing the five contributions is necessary and sufficient for that one block to equal its prescribed target `2J-I`, once the local classes are fixed. Each local class is the complete count-signature class of the authenticated31110-triple catalogue; that catalogue already imposes within-triplicate column caps and the local Gram upper bounds.

Write the five complete projected populations as P0,...,P4. Enumerate `A={u0+u1}` and `B={u2+u3+u4}` by complete Cartesian products, without target pruning. The target T is attainable exactly when some a in A has `T-a` in B. This gives both a complete infeasibility check and a literal five-option witness. It is independent of the producer's bounded DP recurrence and saved predecessor tables. This audit does not claim to have replayed all producer DP prefix states; those are unnecessary premises because the complete Cartesian-complement computation replaces them.

The cache key contains the target and all five ordered populations, each with every matrix entry. Every profile/pair reconstructs this key from its actual raw count classes. Reusing an identical finite problem does not multiply the number of independent arithmetic verifications. The report separately counts unique cache problems and profile/pair applications. Equal class sizes or equal scalar extrema alone do not justify cache reuse.

For each of the six global fibre permutations, relabel every selected vertex's fibre. Each local colour word maps to another balanced word; sorting the three transformed words only permutes columns inside that support group. The complete local catalogue is preserved, and a block matrix transforms by the same simultaneous permutation of its rows and columns. The target `2J-I` is invariant. The audit checks the actual catalogue bijections, projected populations and every count table's saved orbit transport. Thus an impossible representative block rules out the corresponding block for all its recorded labelled images. This is a relabelling of a possible realization, not a hypothesis that a target graph has an automorphism.

The scalar gate supplies the authenticated active population; this audit checks every one of its canonical survivors on every nonmatched pair and recomputes the exact survivor/exclusion partition. Prior literal exclusions are not removed or added as distinct cases. Even if all60 blocks of a profile are feasible, their individual choices may disagree on the same support group. The result therefore supplies no global factor, cross-group column-cap compatibility, residual graph or unrestricted target conclusion.

The positive SRG243 control uses its own chosen15-column Gram blocks. It is a genuine factor control for the arithmetic, not a research99 or fixed-support realization.
