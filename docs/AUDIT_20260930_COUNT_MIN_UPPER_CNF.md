the minimum of the two counts. Summing all five contributing groups proves
the necessary inequality. Clipping each minimum at the required target (1 or

intersection maximum, or assert simultaneous Gram realization.

threshold channels from the earlier independently checked count model, all

compare all original assignment IDs literally, reconstruct the new auxiliaries

native attempt, count profile, full factor or target graph.

requires every comparison and corruption control to pass. Limit: 120 seconds
